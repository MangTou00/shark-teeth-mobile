# 鲨鱼牙齿 · 海底策略助手

为《潜水员戴夫》（DAVE THE DIVER）中的鲨鱼牙齿小游戏准备的**非官方策略辅助工具**。手动选择坏牙位置、记录双方回合，页面根据剩余安全牙数提示下一步。适合在手机上边玩边查。

[在线使用](https://labmate-website-6ol.pages.dev/shark-teeth/) · [下载 HTML](https://github.com/MangTou00/shark-teeth-mobile/blob/main/shark-teeth-mobile.html)

## 快速上手

1. 根据当前游戏设置总牙数，默认 20 颗，可调整为 1–60 颗。
2. **自行确认坏牙位置**，选择“从头数”或“倒着数”，再点对应数字。数字代表按下顺序，不是游戏画面里的空间位置。
3. 点击“开始 · 我先手”，查看建议按几颗。
4. 在游戏里实际操作后，回到工具记录自己或对方按下的 1、2 或 3 颗牙，继续查看提示。
5. 记错可点“撤销”；漏记可在右上角菜单使用“校准当前进度”，输入累计已按的安全牙数与下一位行动者。

菜单还提供对局记录、重开同一局、重选坏牙和规则说明。电脑键盘 `1` / `2` / `3` 可记录回合，`Z` 撤销。

## 策略假设与限制

- 双方轮流按连续的 1–3 颗牙，碰到坏牙者输；新对局固定由你先手。
- 坏牙位置和双方操作均由你手动输入。工具不会识别游戏画面、自动找坏牙或替你操作游戏。
- 设轮到你时坏牙前还剩 `S` 颗安全牙：若 `S % 4` 为 1、2 或 3，就按对应颗数，把 4 的倍数留给对方。
- 若 `S` 是正的 4 的倍数，双方都最优时无法保证获胜；建议“试按 1”并不比按 2 或 3 更有数学优势。若 `S = 0`，则已无安全走法。
- 建议依赖上述规则和准确记录，不代表任何局面都能获胜。若实际玩法不同，不应直接套用。

## 离线使用与数据

下载 `shark-teeth-mobile.html` 的原始文件，用浏览器直接打开即可，无需安装依赖、启动服务器或联网。

样式、脚本和图形均包含在单个 HTML 中；工具不连接游戏，也不发送对局数据。**刷新或关闭页面不会保存对局**；重新打开后，可再次选择相同坏牙并用“校准当前进度”接续，旧历史不会恢复。
