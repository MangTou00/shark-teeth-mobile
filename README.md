# 鲨鱼牙齿 · 海底策略助手

一个移动端友好的离线单页工具，用于记录鲨鱼牙齿游戏回合并给出策略建议。

## 使用

下载 `shark-teeth-mobile.html`，用浏览器直接打开，无需安装依赖或启动服务器。

- 设置总牙数（1–60）并选择坏牙的按下顺序。
- 每回合记录你或对方按下的 1–3 颗牙；工具提示安全走法与胜负。
- 支持撤销、进度校准、历史记录和重新开始。
- 键盘 `1` / `2` / `3` 记录，`Z` 撤销。

本工具假定双方轮流按连续的 1–3 颗牙、触碰坏牙者输、你先手。数字表示按下顺序，不是画面中的空间位置。无必胜走法时会明确提示；刷新不保留对局，可用校准恢复进度。

非官方离线工具，不连接或操控游戏，不发送对局数据。本仓库仅包含这个独立页面及说明，不包含 LabMate 项目。
